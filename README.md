# KMCL 我的世界启动器

KMCL 是一款基于 Electron 开发的《我的世界》Java 版启动器，面向国内玩家：下载全程优先走国内镜像，界面全中文，Mod 与整合包资料对接 MC 百科。免安装、解压即用。

作者：**K21400**

---

## 功能特性

### 游戏下载与安装
- 支持下载全部正式版 / 快照版本，默认使用 **BMCLAPI 国内镜像**，可按需切换官方源或自定义镜像
- 安装原版时可同时勾选 **Forge / Fabric / NeoForge / OptiFine**，互斥组合会自动置灰并提示冲突
- 加载器安装兼容新旧两代 Forge 安装器（spec 0 + processors 的 1.7.10 / 1.12.2 / 1.13–1.16.5 均已适配）
- 多源竞速下载：镜像超时、低速或返回异常时自动切换备用节点

### 版本隔离
- 每个游戏版本拥有独立的 `mods`、存档、配置目录，互不干扰
- 版本列表只展示真正可用的版本，加载器版本与原版版本分开归类

### 账号
- 支持 **Microsoft 正版登录**（可进入正版验证服务器）与离线登录
- 登录凭据仅保存在本机用户目录，不写入项目文件

### Mod 与整合包
- 内置 CurseForge / Modrinth 国内镜像资源浏览，按类型分类并提供搜索
- **Mod 名称自动匹配 MC 百科中文社区名称**（如 `Just Enough Items` → JEI物品管理器），英文原名作为副标题
- 详情页展示可选文件版本，并提供一键跳转 **MC 百科** 对应页面
- 安装 Mod 前自动检测前置依赖，询问是否一并安装
- 整合包导入对齐 PCL 用法：**把 .zip / .mrpack 直接拖进窗口**即可识别，弹窗确认后自动下载对应游戏版本与模组加载器
- 导入整合包只保留所需原版与加载器，安装过程中多生成的版本会自动清理

### 启动与运行
- **运行配置自动调节**：按物理内存、Java 大版本与 mod 数量动态计算 `-Xms/-Xmx` 与 GC 参数，也可手动指定
- 自动扫描本机 Java，按版本要求匹配对应 Java 大版本
- 实时运行日志，支持一键导出报错日志为 TXT
- 首次启动缺失文件自动补齐，默认语言设为简体中文

### 界面
- 无边框可缩放窗口，自绘标题栏（最小化 / 最大化 / 关闭）
- 默认我的世界风景背景，可在设置中替换为自定义图片
- 独立的下载进度详情窗口
- 「关于」页展示作者信息，并预留可扩展内容位

## 快速开始

### 方式一：免安装压缩包（推荐）

1. 在 Releases 下载 `KMCL-x.x.x-win-x64.zip`
2. 解压到任意目录（路径不要含特殊符号）
3. 双击 `KMCL.exe` 启动

游戏目录默认为解压位置同级的 `minecraft` 文件夹，配置文件保存在 `%APPDATA%\KMCL`。

### 方式二：单文件便携版

下载 `KMCL-Portable-x.x.x.exe` 直接双击运行，首次启动会自解压到临时目录。

### 环境要求

- Windows 10 / 11 x64
- 已安装 Java：1.16.5 及以下建议 Java 8，1.17+ 需要 Java 17，1.20.5+ 建议 Java 21
- 首次下载版本需要联网

## 从源码运行

```bash
# 安装依赖
npm install

# 开发模式启动
npm run dev

# 普通启动
npm start
```

### 打包发布

```bash
# 同时生成便携版 exe 与免安装 zip，并同步到项目根目录
npm run release
```

其他可用命令：

| 命令 | 说明 |
| --- | --- |
| `npm run dist` | 仅生成便携版 exe |
| `npm run dist:zip` | 仅生成免安装 zip |
| `npm run dist:dir` | 只输出未打包的目录，便于调试 |

构建产物位于 `dist/`，其中 `win-unpacked/` 为解压后的程序目录，可直接运行。

## 项目结构

```
KMCL/
├── src/
│   ├── main/              # 主进程
│   │   ├── index.js       # 应用入口与窗口创建
│   │   ├── ipc.js         # 全部 IPC 接口
│   │   ├── source.js      # 镜像源定义（BMCLAPI / 官方 / 自定义）
│   │   ├── http.js        # 多源竞速下载与校验
│   │   ├── manifest.js    # 版本清单
│   │   ├── version.js     # 版本解析、依赖库合并、JSON 写入
│   │   ├── installer.js   # 原版下载安装
│   │   ├── loaders.js     # Forge / Fabric / NeoForge / OptiFine
│   │   ├── modsource.js   # Mod、整合包资源与 MC 百科中文名
│   │   ├── modpack.js     # 整合包解析、导入与版本清理
│   │   ├── launcher.js    # 启动游戏、内存与 JVM 参数
│   │   ├── tuning.js      # 运行配置自动调节
│   │   ├── java.js        # Java 扫描与版本校验
│   │   ├── auth.js        # 微软正版登录
│   │   ├── instance.js    # 版本隔离目录
│   │   ├── progress.js    # 任务进度
│   │   └── config.js      # 配置持久化
│   ├── preload/           # contextBridge 安全桥接
│   └── renderer/          # 界面（原生 HTML / CSS / JS）
├── build/                 # 应用图标
└── package.json
```

## 常见问题

**下载速度慢或失败？**
在「设置 → 下载源」切换到 BMCLAPI 国内镜像；若仍失败，可尝试自定义镜像。

**启动提示 Java 版本不匹配？**
在「设置 → Java」手动指定合适的 Java 路径，或安装对应大版本的 JDK。

**整合包导入后版本列表多了条目？**
原版与加载器是整合包运行的必需依赖，会自动保留；安装过程多生成的临时版本会被清理。

**启动器数据存在哪里？**
配置与登录凭据在 `%APPDATA%\KMCL`，游戏文件在启动器目录下的 `minecraft` 文件夹。
